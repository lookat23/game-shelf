# Game Shelf

`game-shelf` is a browser game collection. The first included game is `四子棋 / Drop Four`, a local two-player gravity-based four-in-a-row game.

## Games

- `四子棋 / Drop Four`: choose a column, drop a piece to the lowest open slot, and connect four horizontally, vertically, or diagonally.

## Commands

Install dependencies:

```sh
npm install
```

Start the development server:

```sh
npm run dev
```

Run the production build:

```sh
npm run build
```

Run rule tests:

```sh
npm test
```

Run browser E2E tests:

```sh
npm run test:e2e
```

If Playwright browsers are not installed yet, run:

```sh
npx playwright install chromium
```
